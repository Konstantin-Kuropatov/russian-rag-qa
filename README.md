# Построение вопросно-ответной системы с использованием RAG

Годовой проект по направлению «Искусственный интеллект». Система будет находить подходящий фрагмент русскоязычного текста и с помощью языковой модели формировать краткий ответ с указанием источника. Основной акцент — на сравнении способов поиска и проверке качества ответов.

**Команда №14:** Куропатов Константин (индивидуальный проект)

**Куратор:** Ляпин Данила

## Данные

Основной датасет — [SberQuAD](https://huggingface.co/datasets/kuznetsoffandrey/sberquad): русскоязычные фрагменты статей, вопросы к ним и эталонные ответы, отмеченные прямо в тексте. Для оценки поиска также будет использована [версия SberQuAD для retrieval](https://huggingface.co/datasets/kaengreg/sberquad-retrieval) с [разметкой релевантных фрагментов](https://huggingface.co/datasets/kaengreg/sberquad-retrieval-qrels). В ней около 74 тыс. вопросов и 17 тыс. уникальных фрагментов.

Такой набор данных позволяет проверять обе части системы отдельно: нашла ли она нужный фрагмент и насколько точен ответ. В ходе EDA отдельно проверим, можно ли понять вопрос без исходного фрагмента: неоднозначные вопросы выделим в отдельную группу при оценке.
